=== Yuzu Round ===
Requires at least: 6.4
Tested up to: 7.1
Requires PHP: 8.0
License: GPLv2 or later

Locked Round layout for Yuzu Hair & Beauty. Serves the designed static pages so a WordPress / Cloudways / blocks install cannot rewrite the salon layout.

== Installation ==

1. Upload the yuzu-round folder to wp-content/themes.
2. Activate Yuzu Round.
3. The theme creates Home, Prices, Offers, Join our team, and the legal pages, and sets Home as the front page.
4. Use Settings → Permalinks → Post name.

Do not assemble these pages in a block builder. The templates are the design. Editing one of these pages in wp-admin shows the public page. The block canvas stays empty because that text is not what visitors see.

== Price list ==

In wp-admin, open Price list. Edit the services, senior and stylist prices, treatments, and the four homepage From prices, then press Save prices. The Round layout stays locked. Saving clears the Breeze cache when that plugin is active. Restore original prices puts back the list shipped with the theme.
